# Parcial 1: Deep Learning - Fashion MNIST

Este repositorio tiene la solucion del primer examen parcial de la materia de Deep Learning. El objetivo fue desarrollar, entrenar y evaluar una red neuronal para la clasificación de imágenes del dataset Fashion MNIST.

## Contenido del Proyecto
- `Prueba_Parcial1_Deep_Learning.ipynb`: Notebook principal con el desarrollo, entrenamiento y evaluación del modelo.
- Implementación de métricas globales y análisis detallado por clase (Precisión, Recall, F1-score, Especificidad).
